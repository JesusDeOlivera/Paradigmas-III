Tateti

3 fichas por jugador · colocá y después mové

X Jugador X 0
= Empates 0
O Jugador O 0

Reglamento
  1. Juegan dos jugadores: X y O. Cada uno tiene 3 fichas.
  2. Colocación: por turnos, cada jugador coloca una ficha en un punto libre del tablero.
  3. Movimiento: cuando ambos colocaron sus 3 fichas, en cada turno se mueve una ficha propia al punto libre más cercano, siguiendo las líneas del tablero.
  4. Gana quien forma una línea de 3 fichas propias: horizontal, vertical o diagonal.
  5. Empate: si el jugador en turno no tiene ningún movimiento posible, o si la misma posición se repite 3 veces.
  6. El jugador que empieza se alterna en cada partida.
